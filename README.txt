LESTARI AVIARY FARM — PAKEJ WEB APP

Kandungan:
- index.html: aplikasi
- manifest.webmanifest: maklumat pemasangan
- service-worker.js: cache/offline selepas dibuka sekali
- icons/: ikon aplikasi

Ciri:
- 60 kotak sarang (N001–N060)
- Simpan bilangan anak dan catatan setiap kotak
- Pindahkan anak ke sarang besar dengan kiraan automatik
- Sejarah pemindahan
- Backup/pulihkan JSON dan eksport CSV
- Data disimpan pada pelayar/peranti yang digunakan

PENTING:
Untuk dipasang pada iPhone sebagai ikon Home Screen dan fungsi offline, aplikasi perlu diletakkan pada hosting HTTPS. Fail ZIP ini belum dihoskan di internet.
Selepas host HTTPS:
1. Buka pautan aplikasi menggunakan Safari di iPhone.
2. Tekan Share.
3. Pilih Add to Home Screen.
4. Tekan Add.
5. Buat backup JSON secara berkala dari menu Backup.

Data tidak diselaraskan automatik antara telefon/peranti. Backup JSON diperlukan untuk pindah atau pulihkan data.
